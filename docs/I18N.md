# Internationalisation

CareerOS supports `en` (formatted as `en-AU`) and Simplified Chinese `zh-CN`.
Typed English keys live in `src/i18n/en.ts`; Chinese values live in
`src/i18n/zh-CN.ts`. `getTranslation` falls back to English. Components obtain
`t`, the locale and the global setter from `useLanguage`.

Add a key to English first, then add its Chinese value. Tests report incomplete
Chinese coverage. Use helpers in `src/i18n/format.ts` for dates, percentages,
lists and currency. User-entered names, notes, descriptions and URLs are never
automatically translated.
