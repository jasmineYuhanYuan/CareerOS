# Sprint 3 — Career intelligence

Sprint 3 adds typed English/Simplified Chinese infrastructure, locale-aware
formatting, curated opportunity validation and discovery, transparent
multi-dimensional matching, profile-aware contacts and document records,
dashboard opportunity recommendations, and version 3 local persistence.

Version 2 exports migrate without discarding profile workspaces. Version 3 adds
global language and opportunity preferences plus per-profile saved
opportunities, contacts and document metadata. No authentication, scraping,
automatic submission, external AI service or file upload is included.

All bundled opportunities remain sample planning records unless explicitly
marked and validated as an official source.
