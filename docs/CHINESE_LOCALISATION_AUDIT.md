# 简体中文本地化审计

核验日期：2026-08-11

## 本次覆盖

- 统一了机会、职位、申请、行动中心、中国秋招、招聘日历和首页中的状态、筛选、日期与操作标签。
- 中国秋招的岗位卡、今日推荐、详情页、OA／面试情报及核验队列采用中文优先呈现。
- 新增静态标签、词典键一致性、日期、枚举隔离、语言切换数据隔离和中文排版测试。
- 澳洲真实岗位与即将开放项目复用同一展示映射；中文模式不会显示原始的 Open、Upcoming、Official source、Details 或 Deadline 等产品标签。

## 有意保留的英文

- Canva、Atlassian、Microsoft、Google 等官方品牌名。
- TypeScript、React、GitHub、LinkedIn、SQL、AWS、OA 等技术或行业通用名称。
- 官方英文岗位、课程、机构名称及外部 URL。
- 用户填写的备注、下一步行动和材料名称。
- 明确来自官方来源或社区经验、需要保留原意的内容。

## 后续审计规则

每次新增页面或枚举时，运行 `npm run test` 与 `npm run validate:data`。发现新的 CareerOS 自有英文标签时，应加入词典或展示映射；不得通过翻译源数据来掩盖缺失的 UI 翻译。
