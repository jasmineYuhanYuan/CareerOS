# CareerOS

CareerOS is an AI-powered career operating system designed to help university students manage their entire career journey.

## Features

- Internship & Graduate Job Discovery
- Company Database
- AI Resume Review
- AI Cover Letter
- Job Match Analysis
- Graduate School Planner
- Career Roadmap
- Application Tracker
- Interview Preparation

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI API
